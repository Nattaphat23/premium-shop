PREMIUM STORE V6
================
จุดเด่น:
- หน้าแรกไม่บังคับ Login: ลูกค้าเข้าดูสินค้าได้ก่อน
- สมัครสมาชิกก่อนใช้ Wallet / เติมเงิน / ซื้อสินค้า
- Login / Register
- เติมเงินด้วยยอดที่เลือก
- แนบสลิป "รูปจริง" จากมือถือ/คอม
- Admin เห็นรูปสลิปและกดอนุมัติ/ปฏิเสธ
- - ซื้อสินค้าและหัก Wallet
- Stock บัญชีสินค้า
- Admin ส่งบัญชีให้ลูกค้า
- ลูกค้าเห็น Email/Password/PIN/วันหมดอายุหลังจัดส่ง
- Admin ตั้ง QR พร้อมเพย์ของร้านได้

เปิด:
1. ติดตั้ง Node.js
2. เปิด Terminal ในโฟลเดอร์นี้
3. node server.js
4. เปิด http://localhost:8080

หมายเหตุ:
ระบบตรวจสลิปในเวอร์ชันนี้เป็น "การตรวจโดยแอดมินจากรูปสลิป" ไม่ใช่การตรวจสอบกับธนาคารอัตโนมัติ
ถ้าจะตรวจอัตโนมัติจริง ต้องเชื่อมผู้ให้บริการตรวจสอบสลิป/ธนาคารและทำ backend production
ก่อนใช้งานจริงควรเพิ่ม HTTPS, database จริง, password hashing ที่แข็งแรง, session store, rate limiting, audit log, file storage และการป้องกันการปลอมแปลงสลิป

V7: ไม่มี Wallet / ไม่มีเติมเงินล่วงหน้า
- ลูกค้าสร้างออเดอร์ก่อน
- ระบบกำหนดยอดชำระจากยอดออเดอร์
- ลูกค้าแนบสลิปต่อออเดอร์
- Admin เห็นสลิป + ยอดออเดอร์ + ช่องกรอกยอดที่เห็นในสลิป
- ระบบไม่ให้ Admin อนุมัติถ้ายอดที่กรอกไม่ตรงยอดออเดอร์
- อนุมัติแล้วจึงเปลี่ยนเป็น paid และสามารถจัดส่ง Stock ได้
