# Premium Shop Mobile

ร้านค้า Premium แบบ mobile-first ตามภาพอ้างอิง

## มีอะไรให้แล้ว
- หน้าเว็บแนวตั้ง ใช้งานมือถือเป็นหลัก
- สมัครสมาชิก / เข้าสู่ระบบก่อนสั่งซื้อ
- ตะกร้าสินค้า + จำนวนสินค้า
- Admin เพิ่ม / แก้ไข / ลบสินค้าเองได้
- Admin ตั้งชื่อร้าน + ธนาคาร + เลขบัญชี + ชื่อบัญชี
- ลูกค้าสร้างออเดอร์และแนบสลิปในเว็บ
- Admin ดูสลิปและกดอนุมัติ / ไม่ผ่าน
- เก็บข้อมูลใน `data/db.json`
- ไฟล์สลิปอยู่ใน `uploads/`
- ใช้ได้กับ Render / VPS / Node.js

## เปิดในเครื่อง
```bash
npm install
npm start
```
แล้วเปิด `http://localhost:8080`

## Admin
ค่าเริ่มต้น:
- Email: `admin@local`
- Password: `1234`

แนะนำให้เปลี่ยนผ่าน Environment Variables:
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`

## หมายเหตุเรื่องตรวจสลิป
เวอร์ชันนี้เป็นการ **แนบสลิปให้แอดมินตรวจเอง** และเปลี่ยนสถานะออเดอร์จากหน้า Admin
ถ้าต้องการตรวจสลิปอัตโนมัติ ต้องเชื่อม API ของผู้ให้บริการตรวจสลิป/ธนาคารเพิ่มเติม
